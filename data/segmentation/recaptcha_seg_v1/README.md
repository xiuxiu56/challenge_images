# reCAPTCHA 分割数据模板

分割训练使用完整挑战图片和 YOLO 多边形标签，与分类目录结构不同。

```text
recaptcha_seg_v1/
├── images/
│   ├── train/
│   └── val/
├── labels/
│   ├── train/
│   └── val/
├── data.yaml.example
└── README.md
```

每行标签格式：

```text
类别编号 x1 y1 x2 y2 x3 y3 ...
```

坐标归一化到0～1。一张图片可以有多个目标实例；纯负样本使用同名空标签文件。
完成数据准备后，将 `data.yaml.example` 复制为 `data.yaml`，再从主菜单选择“训练 YOLO26 实例分割模型”。

建议优先标注两类样本：

1. 完整挑战图中的正确目标实例，多边形尽量贴合真实边界。
2. 容易误检的负样本，例如把汽车局部识别成摩托车、把路灯识别成红绿灯。

数据集划分应以完整原图为单位，避免同一张挑战图的相邻格子同时
出现在训练集和验证集中。
